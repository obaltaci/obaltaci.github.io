Privacy Policy

Content Hub · effective 2 November 2026 · home

Who this applies to

Content Hub is a private tool written and used by one person, Omer Baltaci ("the owner"). It runs on the owner's own computer. It has no other users, so this policy describes how the tool handles the owner's own Google account data.

What data the tool accesses

When the owner connects the tool to YouTube, the tool receives from Google:

  • permission (an OAuth access token and refresh token) to upload videos to the owner's YouTube channel;
  • read-only access to the owner's YouTube channel information and to the processing status of the videos the tool uploaded.

The tool does not request or access any other Google data, such as email, contacts, files or other people's accounts.

How the data is used

The access is used only to upload the owner's own videos, with the title and description the owner approved, and to check that each upload finished. It is not used for advertising, profiling, analytics or any other purpose.

Where the data is stored

The tokens are kept in a protected file on the owner's own computer. The tool has no server, no database in the cloud and no analytics. Nothing is uploaded anywhere except the videos the owner chose to publish, which go to YouTube itself.

Sharing

The data is not sold, shared or transferred to anyone. Content Hub's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The tokens stay on the computer until the owner removes them. The owner can revoke the tool's access at any time in the Google account settings (Security → Third-party access) and can delete the token file from the computer.

Children

The tool is not directed at children and collects no personal information from anyone.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
